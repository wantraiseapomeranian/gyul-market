# 귤상회 DESIGN

> 어떻게 보이고 움직이는지 정의한다. 요구사항 ID(FR/NFR)는 [PROJECT.md](PROJECT.md)를 따른다.
> 기준 시안: 선과장 v2(Phase 2.5 승인) + 이 문서의 Phase 3 변경. 상태: 2026-11-05 · G3 승인 전

## 1. 콘셉트

**선과장(選果場)**: 국내 신선식품몰의 정보 구조 위에, 감귤 유통 현장의 서류 언어를 입힌다.

- **화면 흐름이 곧 서류 흐름이다**: 선별 태그 → 당도 검사표 → 도장 → 판정서. 같은 문서번호(No.0412)가 마지막까지 이어진다.
- **브랜드는 세 곳에서만 말한다**: 워드마크(選 인장), 도장, 주 버튼. 나머지는 흰 바탕과 차콜.
- **반전은 새 화면이 아니라 마지막 서류로 온다**: 흰 쇼핑몰이 동백 레드 판정서로 뒤집힌다.

## 3. 레이아웃

- 기준 폭 360~430px. 320px에서도 깨지지 않는다.
- 431px 이상은 가운데 430px 기둥으로 두고 바깥은 `band` 색. 하단 바와 전환 레이어도 기둥 폭에 맞춘다.
- 하단 바 높이는 77px(여백 10 + 버튼 56 + 여백 10 + 위 테두리 1) + `env(safe-area-inset-bottom)`이다. 본문 하단 여백은 110px + safe area로 잡아 내용이 가리지 않게 한다.
- 수량 시트는 430px 이하에서 화면 아래에 붙고(폭 100%, 최대 430px), 431px 이상에서는 폭 400px 가운데 모달이 된다. 안내 모달은 좌우 16px(최대 360px) 가운데.
- `viewport-fit=cover`. 측정 화면 높이는 `100dvh`, 지원하지 않으면 `100vh`.

### ① 상품 상세 (`product`)

위에서 아래로 배치한다.

   - 설명 '노지 온주밀감 · 2S~M 크기 혼합' 14px `mute`
   - 할인 표기 '14%' + 취소선 '35,000원'. 14%는 `ink`로 둔다(§9.2, `camellia` 화면당 세 곳)
   - 가격 **29,900원** + '100g당 299원' 12.5px `mute`
4. 8px 띠
5. 정보 행(라벨 64px): **배송** 무료배송 / **원산지** 국내산(제주) / **품종** 노지 온주밀감 / **규격** 10kg · 2S·S·M 혼합 / **보관** 서늘하고 그늘진 곳

9. 8px 띠 + 안내: 배송 안내 / 교환·환불 안내(목록)

### ①-1 수량 시트 · ①-2 당도 검사 안내 모달 (상품 위에 겹침)

1. 상품 **구매하기** → QtySheet(기본 1박스, 1~5박스, 총액 = 29,900원 × 수량)
2. QtySheet **구매하기** → NoticeModal. 시트는 모달 아래에 그대로 열려 있다.
   - '저희 귤상회는 고객님께 달콤한 귤을 보내드리기 위해 구매 전 당도 검사를 진행하고 있습니다.'
   - '검사는 약 10초 정도 소요됩니다.'
3. **당도 검사 시작하기** → ② 귤 선택(기존 게임 첫 단계)

- 모달을 닫으면 수량 시트로, 시트를 닫으면 상품으로 돌아간다. 수량은 상품으로 돌아와도 유지된다.
- 주문 접수·결제 완료·배송지 입력처럼 일어나지 않는 결과는 보여 주지 않는다(D5).
- 시트·모달에는 가상 상점 고지를 두지 않는다(FR-15).

## 10. 접근성 설계

- **대비**: §2 표의 수치를 따른다. 레드 위 흰 글자 0.88 이상, 미검사 행 글자는 `mute`(흐리게 하지 않는다).
- **초점**
  - 화면이 바뀌면 그 화면의 제목(`tabindex=-1`)으로 초점을 옮기고 맨 위로 스크롤한다.
  - 초점 링은 2px `camellia`, 바깥 2px. 레드 위(엔딩)에서는 흰색.
  - 시트·모달이 열리면 창 안 첫 버튼(닫기)으로, 닫히면 연 버튼(상품 **구매하기** / 시트 **구매하기**)으로 초점을 돌려준다. WebKit은 눌린 버튼에 초점을 주지 않으므로 복귀 대상을 코드로 지정한다.
- **터치 영역**: 44×44px 이상. 시료는 행 전체가 라벨이다.
- **의미 구조**: 시료 선택은 `fieldset` + 라디오. 측정 과일은 `button`(aria-label '귤 누르기, 5번 중 {n}번 누름').
- **낭독**: 측정값·횟수는 `aria-live="polite"` 영역에서 탭마다 '{n}번째, {v} 브릭스'로 읽는다. 판정 전환은 '판정서를 발급하고 있습니다'로 읽는다.
- **도장**: 장식 도장은 `aria-hidden`. '검사필'은 '검사 완료' 숨김 문구를 함께 둔다.
- **축소 모션**: §6 표를 따른다.
- **글자 확대**: OS 글자 130%에서 겹침이 없어야 한다.
- **색만으로 전달하지 않는다**: 시료는 기호(A·B·C)와 규격 글자로 구분한다.
